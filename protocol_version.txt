Protocol v2, 2026-09-04

Change from v1: switched from issue-first to PR-first candidate enumeration.
Reason: issue-to-PR linking in the target repository is inconsistent (v1
yielded 0-4 candidates from 76 bug-labeled issues due to unlinked or
squashed fix PRs). PR-first selection uses merged PRs whose titles match
bug-fix language and whose diffs are 3-300 LOC across at most 4 files,
with the same rendering/layout/key-binding exclusion filter.
Candidate pool size at protocol v2: 64 candidates from 774 closed PRs.

prompt_toolkit/key_binding/, plus docs/tests/examples/config

Protocol v3, 2026-09-04
Change from v2: harness now resets to per-task pre-fix commit (parent of
reference PR merge commit) and restores reference-PR test files as the
correctness oracle, instead of running against a single frozen HEAD.
Reason: v2 harness ran agents against a repo state that already contained
every fix in the task list; tests trivially passed and provided no signal.
The frozen_commit.txt file remains as a metadata pin for the candidate
enumeration (task selection freeze), not as the per-run repo state.

Test-file identification heuristic: files under tests/, or with basename
starting test_, or ending _test.py.

Oracle: pytest on the identified test files. If a task has no test files
in its reference PR, the operator is warned and the outcome falls back to
the full-suite pass check (recorded but marked as no-oracle in the run
summary).

Protocol v6, 2026-09-05
Change from v5: target repository changed from
prompt-toolkit/python-prompt-toolkit to pallets/click.
Reason: v5 enumeration on prompt-toolkit yielded only 9 candidates because
maintainers did not consistently add regression tests for bug-fix PRs
(49 of 156 merged bug-fix PRs had no test file). Click's project culture
(Pallets convention) requires a test with every fix, so the test-oracle
prerequisite yields a much larger pool from a comparable enumeration run.

IMPL_EXCLUDE_PATTERNS retargeted to click-specific platform-dependent
modules: _termui_impl.py, _winconsole.py, shell_completion.py.

All other filters (BUG_TITLE_PATTERNS, MAX_LOC=300, MAX_FILES=4,
MIN_LOC=3, test-file requirement) preserved from v5. Random-draw seeds
(42 for tasks, 137 for holdout) preserved.

Author conflict-of-interest disclosure updates: author is not a
contributor to pallets/click. The random-draw and impl-exclude filters
remain as methodological safeguards independent of prior contribution.

Frozen commit for candidate enumeration: see frozen_commit.txt.

Total pilot cost approximately 1.30 USD.

Changes locked in this version:
1. Model tier: claude-sonnet-5 confirmed for full study.
2. Sampling parameters: not user-configurable for this model version;
   temperature and top_p are deprecated. Determinism characterized via K
   repetitions.
3. MA Coder iteration cap raised from 12 to 25 (matching SA), based on
   T04 MA hitting the previous cap in codebase exploration before proposing
   an edit. Fair-comparison alignment with SA.
4. MA harness message-accumulation fix: Coder now maintains a persistent
   message history across its iterations, and four operator-feedback
   channels (o/a/t/d/x) are exposed. Two aborted pre-fix pilot runs
   documented as harness-development artifacts, excluded from study data.
5. Pytest invocation standardized: PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 and
   python -m pytest, to isolate from system-installed pytest plugins.
6. Full-suite regression check will report False on all runs due to a
   pre-existing PytestRemovedIn10Warning collection error in
   tests/test_basic.py on the frozen commit; unrelated to any agent's
   diff, verified on clean parent commit. Noted in run logs and
   known_environment_issues.md.

Manuscript Sections 1, 3, 6, 7 updated 2026-09-05 to reflect the click
target repository, the pilot findings, and the sampling-parameter
